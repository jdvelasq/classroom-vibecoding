# Diseño de contenido: Fundamentos de data para analítica

## Propósito y límites

Curso optativo de pregrado sobre datos accesibles, confiables, comprensibles y reproducibles para una finalidad analítica. No es prerrequisito ni un curso de Data Engineering, administración de bases de datos o Big Data Analytics.

## Perfil distintivo y fronteras

Su responsabilidad distintiva es preparar la base informacional para análisis confiable. No posee operaciones de producción, arquitectura distribuida, despliegue, analítica predictiva, optimización ni una identidad de ingeniería.
