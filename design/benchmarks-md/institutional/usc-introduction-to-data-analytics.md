**Course Description**
Data is now an integral part of our lives and to be successful in today’s business landscape, we need to be
able to leverage data to make critical business decisions. This course will teach students how to use data to
make those decisions confidently.

**Learning Objectives**
After completing this course, students will be able to:

- Use MS Excel, MS Access, SQL, NoSQL, MongoDB and leading industry tools

- Model database and formulate/code database queries

- Pose questions, collect relevant data, analyze data, interpret data and provide insights

- Present data-driven insights using data visualization and dashboards

- Tell compelling stories with data

**Prerequisite(s):** None
