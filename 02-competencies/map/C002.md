# C002. Preparar los datos para una pregunta analítica

## Enunciado

Obtener, integrar, limpiar y validar los datos que una pregunta analítica
necesita, para producir un conjunto de datos analítico documentado y de
calidad conocida.

## Subcampos

- ingeniería de datos para la analítica: por domain.md; el subcampo es
  «obtener, integrar y preparar los datos que una pregunta analítica
  necesita».
- analítica descriptiva: por domain.md; la preparación sirve a toda
  pregunta.
- analítica diagnóstica: por domain.md; la preparación sirve a toda
  pregunta.
- analítica predictiva: explícita [E0004 p. 7, paso 2].
- analítica prescriptiva: por domain.md; la preparación sirve a toda
  pregunta.

## Conocimientos

- Necesidades de datos derivadas de la pregunta y evaluación de las
  fuentes disponibles [E0001 p. 5, tareas 3.1–3.2; E0004 p. 7, paso 2;
  E0005 p. 70, *DG-Data Acquisition*].
- Estructuras de datos y relaciones entre fuentes [E0001 p. 5, tarea 3.2;
  E0143 §6, Databases/SQL].
- Integración de fuentes heterogéneas: correspondencia de esquemas,
  integración entre dominios y extracción de información desde texto
  e imágenes [E0005 p. 71, *DG-Data Integration*, *DG-Working with
  Various Types of Data*].
- Reducción y compresión de datos para quitar redundancia antes del
  análisis [E0005 p. 72, *DG-Data Reduction and Compression*].
- Tabla base analítica: un registro por entidad para el modelado
  supervisado [E0004 p. 7, paso 2].
- Dimensiones de calidad de los datos: errores, faltantes, atípicos, y
  su efecto en la representatividad de los datos para el modelado
  [E0001 p. 5, tarea 3.6; E0004 p. 7, paso 3; p. 8; E0006 p. 5,
  módulo 2].
- Privacidad, seguridad y gobierno de los datos [E0001 p. 5, Dominio III;
  E0005 p. 70, *DG-Data Acquisition*, normas de seguridad y privacidad].
- Muestreo representativo y partición en entrenamiento y prueba
  [E0004 p. 7, paso 2].

## Habilidades

- Adquirir datos de sistemas distintos, eligiendo la fuente y la técnica
  de adquisición según sus características y las de la aplicación
  [E0001 p. 5, tarea 3.4; E0004 p. 7, paso 2; E0143 §3; E0005 p. 70,
  *DG-Data Acquisition*].
- Limpiar, armonizar, transformar, unir y validar datos [E0001 p. 5,
  tarea 3.5; E0143 §3; E0004 p. 4, «Prepare los datos»].
- Agregar y transformar datos hasta una tabla analítica [E0004 p. 7,
  paso 2; E0143 §3, SQL: joins, window functions].
- Evaluar la calidad de los datos e informar los hallazgos [E0001 p. 5,
  tareas 3.6–3.7; E0143 §3, «validate data»].
- Elaborar un plan de gestión de datos [E0001 p. 5, tarea 3.3].
- Revisar el planteamiento del problema a la luz de los datos
  [E0001 p. 5, tarea 3.8].

## Evidencia de desempeño

- Informe de hallazgos de datos: calidad, análisis de impacto y plan de
  gestión de datos [E0001 p. 5, tarea 3.7].
- Tabla base analítica con un registro por cliente para modelar el
  abandono [E0004 p. 7, paso 2].
- Práctica de certificación: validar los datos de un problema de negocio
  y calcular métricas [E0143 §3, §8].
- Herramientas de ejemplo: SQL y PostgreSQL, pandas, dplyr [E0143 §9];
  Hadoop como almacenamiento [E0004 p. 4].
