# Catalog operating boundary

Every dataset and case in this catalog is evaluated for the course owner's
**private classroom use** only. The catalog is metadata: it does not host,
copy, package, or redistribute source datasets, code, or book content.

This boundary applies to every collection task and every source folder. A
record may support selection for a privately taught activity when its source,
access route, contents, and limitations are documented. It must still preserve
the original provider's terms and state any requirement for learners to obtain
the material directly from that provider.

Private classroom use is not a claim that a dataset is public domain, openly
licensed, or redistributable. Records with conditional, ambiguous, restricted,
or source-specific terms must make that condition explicit. They are not to be
included as raw files in course-distribution materials.

`catalog/tasks/` defines source-specific collection procedures. Source folders
contain selection metadata, organized by the corresponding `sNN` task.
