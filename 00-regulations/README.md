# Normativa

Marco que rige el proceso de diseño curricular: cómo se formulan
competencias, habilidades y resultados de aprendizaje, y cómo se armonizan
los programas. No es evidencia sobre qué es la analítica, por eso tiene su
propio ciclo, fuera de `01-evidence/` y de la skill `selecting-evidence`.

Los documentos se agregan a mano: el PDF en `pdf/` y su conversión en `md/`.

```bash
uv run design/tasks/s01-convert-benchmarks.py --input 00-regulations/pdf --output 00-regulations/md
```
