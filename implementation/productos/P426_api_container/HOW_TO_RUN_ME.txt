Este PRE publica localmente una capacidad analítica mínima. Docker ejecuta el servicio en un contenedor y conecta su puerto con el computador del estudiante.

1. Con Docker Desktop abierto, desde la raíz del repositorio construya la imagen:

   docker build --file implementation/productos/P426_api_container/Dockerfile --tag pre22-api .

   En `--file`, se indica el Dockerfile de la actividad. En `--tag pre22-api`, `--tag` asigna el nombre de la imagen. El punto `.` usa la raíz del repositorio como contexto, por lo que la imagen instala el `requirements.txt` canónico.

2. Inicie el servicio:

   docker run --rm --publish 8000:8000 pre22-api

   `--rm` elimina el contenedor temporal cuando se detenga. `--publish 8000:8000` conecta el puerto 8000 de su computador con el puerto 8000 del contenedor. Mantenga esta terminal abierta.

3. En otra terminal, pruebe la capacidad:

   curl --request POST http://localhost:8000/score --header "Content-Type: application/json" --data '{"daily_units_produced":4200}' --output submission/score_response.json

   En `curl`, `--request POST` indica el método de la solicitud, `--header` declara que se envía JSON, `--data` contiene el dato de entrada y `--output` guarda la respuesta en `submission/score_response.json`. Abra ese archivo: la respuesta debe incluir `risk` y `threshold`.

4. Vuelva a la primera terminal y presione Control+C para detener el servicio.
