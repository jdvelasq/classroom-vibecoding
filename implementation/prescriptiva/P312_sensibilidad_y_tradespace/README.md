# Sensibilidad y revisión de una política

## Problema

Un servicio de entrega debe definir cada mes su promesa de entrega. La política
no concluye al comparar alternativas: ofrece entrega en un día solo si la
ganancia de retención esperada supera el umbral que cubre el costo, el costo
cabe en el presupuesto y la incertidumbre no cruza dicho umbral. Cuando uno de
estos supuestos cambia, la política se revisa, se suspende o se escala a la
dirección comercial.

El tradespace es evidencia para esta política; no es el producto terminal.
