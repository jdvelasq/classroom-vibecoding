13/10/26, 4:42 p.m. Certificado Profesional de Analista de datos de IBM | Coursera


Prepárese para una carrera en el campo de alto crecimiento de la Analítica de datos. En este programa, usted aprenderá en la demanda de habilidades como

Python, Excel y SQL para conseguir trabajo listo en tan sólo 4 meses.


El análisis de datos es el proceso de recopilación, almacenamiento, modelado y análisis de datos que pueden informar la toma de decisiones ejecutivas, y la

demanda de analistas de datos cualificados nunca ha sido mayor.


Este programa le enseñará los conocimientos básicos de datos que los empleadores están buscando para los puestos de analítica de datos de nivel de entrada. No

solo lo ayudará a comenzar su carrera en análisis de datos, sino que también proporciona una base sólida para el desarrollo profesional futuro en otros caminos,

como la ciencia de datos, la inteligencia artificial, el aprendizaje profundo o la ingeniería de datos.


Aprenderás las últimas habilidades y herramientas utilizadas por los analistas de datos profesionales, incluidas hojas de cálculo Excel, Python, Pandas, Numpy,

Jupyter Notebooks, Cognos Analytics y más. Trabajarás con una variedad de fuentes de datos y escenarios de proyectos para adquirir experiencia práctica con la

manipulación de datos y la aplicación de habilidades analíticas. También tendrás la opción de aprender cómo se utilizan las herramientas y técnicas de IA

generativa en el análisis de datos.


Además de una cartera de proyectos y un certificado profesional de IBM para mostrar su experiencia, usted ganará una insignia digital de IBM y obtener acceso a

los recursos de carrera para ayudarle en su búsqueda de empleo.


Este programa está recomendado por ACE® y FIBAA; cuando lo complete, podrá obtener hasta 12 créditos universitarios y 6 créditos ECTS.


Proyecto de aprendizaje aplicado


A lo largo del programa, completará proyectos prácticos y laboratorios y adquirirá un firme dominio de las habilidades técnicas necesarias para recopilar, manejar,

extraer y visualizar datos de forma eficaz, así como de las habilidades interpersonales para trabajar con las partes interesadas y contar historias con datos para

atraer a su audiencia.


Proyectos


Importar, depurar y analizar el inventario de vehículos de flota con tablas dinámicas de Excel


Utilizar datos de indicadores clave de rendimiento (KPI) de ventas de automóviles para crear un cuadro de mandos interactivo con visualizaciones


Extraiga y grafique datos financieros con la biblioteca Python de análisis de datos Pandas


Utilice SQL para consultar conjuntos de datos demográficos de censos, delincuencia y escuelas


Manipule datos, trace gráficos y cree modelos de regresión para predecir los precios de la vivienda con las bibliotecas Python de ciencia de datos


Cree un panel de control dinámico en Python para supervisar, informar y mejorar la fiabilidad de los vuelos nacionales de EE.UU


Al final del programa, completará un proyecto final del mundo real diseñado específicamente para mostrar sus habilidades de analista de datos recién aprendidas.
