### **Python para Data Science**


En un mundo en el que los datos se consideran un producto de


primera necesidad, es fundamental que los profesionales de data


science posean amplios conocimientos de los aspectos que intervienen


en el diseño y la escritura de código en Python. Además, han de saber


emplear este mismo código de manera creativa y útil a la hora de


resolver problemas reales.

### **Sobre el programa**

Nuestro programa de ocho semanas Python para Data Science es


una introducción a los conceptos básicos del lenguaje de


programación Python. Se trata de un programa de elevado nivel


técnico basado en proyectos, que incluye muchos ejemplos


prácticos que te serán de utilidad para, más adelante, tener la


oportunidad de crear y ejecutar tus propios proyectos en Python.


Este programa te preparará para:


- Entender el lenguaje de programación Python.


- Ser un experto en el análisis y la manipulación de datos.


- Escribir código de producción en Python.


- Entrenar y evaluar modelos de machine learning.


- Diseñar y optimizar código de Python para lograr una mejora del


rendimiento y un aumento de la velocidad.


- Escribir código en Python para procesar grandes conjuntos de


datos de manera eficiente.


- Preparar modelos de machine learning con el fin de utilizarlos


en producción.

### **Guía del programa**

El programa Python para Data Science cubre los siguientes temas:


Módulo 1: Las Funcionalidades Básicas de Python


- La declaración de variables, las operaciones matemáticas y lógicas,


los tipos de datos y los contenedores


- Las condicionales (if, elif, else)


- Las iteraciones (bucles for y while)


- La comprensión


- Los errores y las excepciones


Módulo 2: Las Clases y las Funciones Definidas por
el Usuario


- Las funciones definidas por el usuario (FDU)


- La mejora de las FDU


- Introducción a las clases


- El desarrollo de regresiones lineales


Módulo 3: El Análisis y la Manipulación Básica de Datos


- El uso de pandas para cargar datos externos


- La manipulación de estructuras de datos y arrays con NumPy


- Pandas y NumPy en acción


- La unión y concatenación de estructuras de datos mediante pandas


- La creación de visualizaciones a través de Seaborn

<!-- fin de página 8 -->

Módulo 4: El Análisis y la Manipulación de Datos Avanzados


- El uso del broadcasting


- Las operaciones de matrices y elementos para una manipulación


de datos eficiente


- Conceptos avanzados para la manipulación de estructuras de


datos en pandas


- Las métricas de distancia, las matrices de distancia y las


distribuciones con SciPy


Módulo 5: El Entrenamiento y la Evaluación de Modelos de
Machine Learning (ML)


- La normalización de datos con Sklearn


- La extracción de atributos con Sklearn


- El uso de Sklearn para entrenar modelos de predicción,


clasificación y de ML no supervisado


- La evaluación de modelos de predicción, clasificación y de


aprendizaje no supervisado


- La validación cruzada


Módulo 6: La Paralelización del Entrenamiento de Modelos

y Programas Mediante el Multiprocesamiento


- Introducción a la paralelización


- El parámetro n_jobs y los random forests en Sklearn


- La paralelización de la técnica grid search en Sklearn


- El multiprocesamiento en Python


- El desarrollo de random forests a través de los módulos de


multiprocesamiento y los árboles de decisión de Sklearn

<!-- fin de página 9 -->

Módulo 7: La Paralelización de Web Scrapers Mediante la
Programación Multihilo


- La programación multihilo frente al multiprocesamiento


- La programación multihilo en Python


- La extracción de datos a través del módulo request


- La programación multihilo para la extracción de datos en paralelo


Módulo 8: La Implementación de Modelos


- Entrenar y guardar un modelo Sklearn


- Definición de API y creación de una API de Flask básica


- El desarrollo de una API de Flask para hacer predicciones a través


de un modelo de ML guardado


- La puntuación por lotes a través del multiprocesamiento
