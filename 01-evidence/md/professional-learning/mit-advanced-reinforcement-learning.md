### **Explore the cutting-edge of RL research**

Reinforcement learning (RL) is transforming machine learning
applications across industries—and its potential is only beginning
to be tapped. From natural language processing and computer vision
to self-driving cars and gaming, this paradigm offers practical
applications in industries as diverse as transportation, retail, finance,
urban planning, and healthcare.


In this accelerated, two-day course, you’ll receive an advanced
overview of the cutting-edge RL topics that are driving exciting
advancements in machine learning. Through interactive lectures and
exercises, you’ll acquire a multi-faceted glimpse into the development
and potential of RL, from the perspectives of statistics, optimal
control, economics, operational research, and other disciplines.


You will additionally have the opportunity to put your learning into
practice during hands-on clinics, in which you will use advanced
algorithms to solve real-world problems, and then discuss your
solutions with the class and instructors during office hours.
You will leave the course armed with a broad understanding of
reinforcement learning as a tool, mathematical framework,
and an active field of study.

**LEARNING OUTCOMES**


Each problem is unique: the tradeoffs are unique, the challenges are different.
Therefore, simply applying Deep RL algorithms will not work. For instance, you might
have an existing dataset that can be leveraged or there is already a working system
that only needs to be improved or maybe the problem has a long-time horizon, or
that the environment is constantly changing. First what RL framework to use? Is it
offline reinforcement learning, model-based RL, curriculum learning, hierarchical
RL, learning from demonstrations, multi-agent RL? Second, how do these algorithms
work and how to use them. This course will address these questions and practical
challenges in using Deep RL algorithms. By the end of the course you will have rules
of thumb to decide which RL framework to use and how to implement it.


By completing this course, you will enhance your ability to:


**›**
 Improve the performance of supervised learning systems by fine-tuning
with RL methods

**›**  Decide when to use an analytical model or when to use a learned model.
Learn about Model-Based RL

**›**  Learn techniques for applying Deep RL methods to practical problems
when it is impossible to collect large amounts of data

**›**  Determine the reinforcement learning framework (e.g. goal-directed,
hierarchical, offline reinforcement learning, bandits) that is best-suited
to solve a specific problem

**›**  Learn about RL algorithms that can generalize to new goals

**›**  Learn more about what to do if the reward is very sparse or the time horizon
is very long

**›**  Select the most promising algorithms for an already-formulated reinforcement
learning problem

**›**  Recognize the limitations of reinforcement learning in order to judge whether
a situation is suited for these strategies
