13/10/26, 4:49 p.m. MLOps | Operaciones de aprendizaje automático | Coursera


Esta completa serie de cursos es perfecta para personas con conocimientos de programación, como desarrolladores de software, científicos de datos e

investigadores. Adquirirá conocimientos críticos de MLOps, incluido el uso de Python y Rust, la utilización de GitHub Copilot para mejorar la productividad y el

aprovechamiento de plataformas como Amazon SageMaker, Azure ML y MLflow. También aprenderá a afinar los modelos lingüísticos de gran tamaño (LLM)

utilizando Hugging Face y comprenderá el despliegue de modelos binarios incrustados sostenibles y eficientes en el formato ONNX, preparándole para el éxito en

el campo en constante evolución de los MLOps


A través de esta serie, empezará a adquirir habilidades para diversas trayectorias profesionales:


1. Ciencia de datos: analice e interprete conjuntos de datos complejos, desarrolle modelos ML, implemente la gestión de datos e impulse la toma de decisiones

basada en datos.


2. Ingeniería del Aprendizaje Automático ~~-~~ Diseñe, construya y despliegue modelos y sistemas de ML para resolver problemas del mundo real.


3. Arquitecto de soluciones de ML en la nube ~~-~~ Aproveche las plataformas en la nube como AWS y Azure para diseñar y gestionar soluciones de ML de forma

escalable y rentable.


4. Gestión de productos de Inteligencia Artificial (IA) ~~-~~ Acorte la distancia entre los equipos de negocio, ingeniería y ciencia de datos para ofrecer productos de

IA/ML impactantes.


Proyecto de aprendizaje aplicado


Explore y practique sus conocimientos de MLOps con ejercicios prácticos y repositorios de Github.


1. Construir un script en Python para automatizar el preprocesamiento de datos y la extracción de características para modelos de aprendizaje automático.


2. Desarrollar una solución ML/AI del mundo real utilizando la programación por pares de IA y GitHub Copilot, demostrando su capacidad para colaborar con la IA.


4. Creación de aplicaciones web y herramientas de línea de comandos para la interacción con modelos de ML utilizando Gradio, Hugging Face y el marco Click.


3. Implementación de tareas de ML aceleradas por GPU utilizando Rust para mejorar el rendimiento y la eficiencia.


4. Entrenamiento, optimización y despliegue de modelos ML en Amazon SageMaker y Azure ML para MLOps basados en la nube.


5. Diseño de un pipeline completo de MLOps con MLflow, gestionando proyectos, modelos y características del sistema de seguimiento.


6. Puesta a punto y despliegue de grandes modelos lingüísticos (LLM) y modelos en contenedores utilizando el formato ONNX con Hugging Face. Creación de

demostraciones interactivas para mostrar eficazmente su trabajo y sus avances.
