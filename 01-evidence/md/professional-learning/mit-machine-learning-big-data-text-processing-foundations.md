Machine learning is a rapidly expanding area with a diverse
collection of tools and approaches. Successfully applying such
methods to real tasks may seem to require expertise that many
do not possess. However, all these methods share the same basic 
concepts, use the same building blocks.


Understanding these basics, formulations, and when they
are appropriate, is key to using machine learning techniques 
successfully in practice. This foundational course covers the
essential concepts and methods in machine learning, providing
participants with an entry level expertise they need to get started
and quickly move ahead.
