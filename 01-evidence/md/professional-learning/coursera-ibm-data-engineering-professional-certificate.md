13/10/26, 4:49 p.m. Certificado Profesional de Ingeniería de datos de IBM | Coursera


Prepárate para una carrera en el campo de alto crecimiento de la ingeniería de datos. En este programa, usted aprenderá en la demanda de habilidades como

Python, SQL y bases de datos para conseguir trabajo listo en menos de 5 meses.


Ingeniero de datos es la construcción de sistemas para recopilar datos, procesar y organizar los datos en bruto en la información utilizable. Los ingenieros de

datos proporcionan la información básica que los científicos de datos y los analistas de inteligencia empresarial utilizan para tomar decisiones.


Este programa le enseñará las habilidades de ingeniería de datos fundamentales que los empleadores están buscando para las funciones de ingeniería de datos de

nivel de entrada, incluyendo Python, uno de los lenguajes de programación más utilizados. También dominará SQL, RDBMS, ETL, Almacenamiento de datos,

NoSQL, Big Data y Spark con laboratorios y proyectos prácticos.


Aprenderás a utilizar el lenguaje de programación Python y las secuencias de comandos shell de Linux/UNIX para extraer, transformar y cargar (ETL) datos.

Trabajarás con Bases de Datos Relacionales (RDBMS) y consultarás datos usando sentencias SQL y usarás bases de datos NoSQL así como datos no estructurados.

También aprenderá cómo se utilizan las herramientas y técnicas de IA generativa en la ingeniería de datos.


Al finalizar, tendrá una cartera de proyectos y un certificado profesional de IBM para mostrar su experiencia. También obtendrá una insignia digital de IBM y

tendrá acceso a recursos profesionales que le ayudarán en su búsqueda de empleo, incluidos simulacros de entrevistas y soporte para el currículum.


Este programa está recomendado por ACE®: cuando lo completes, podrás obtener hasta 12 créditos universitarios.


Proyecto de aprendizaje aplicado


A lo largo de este Certificado Profesional, completará laboratorios y proyectos prácticos que le ayudarán a adquirir experiencia práctica con Python, SQL, bases de

datos relacionales, bases de datos NoSQL, Apache Spark, construcción de pipelines de datos, gestión de bases de datos y trabajo con almacenes de datos.


Proyectos:


Diseñe una base de datos relacional para ayudar a una franquicia de café a mejorar sus operaciones.


Utilizar SQL para consultar conjuntos de datos demográficos de censos, delincuencia y escuelas.


Escribir un script de shell Bash en Linux que realice copias de seguridad de los archivos modificados.


Configure, pruebe y optimice una plataforma de datos que contenga bases de datos MySQL, PostgreSQL e IBM Db2.


Analizar datos de tráfico por carretera para realizar ETL y crear un pipeline utilizando Airflow y Kafka.


Diseñe e implemente un almacén de datos para una empresa de gestión de residuos sólidos.


Mover, consultar y analizar datos en bases de datos MongoDB, Cassandra y Cloudant NoSQL.


Entrene un modelo de aprendizaje automático creando una aplicación Apache Spark.


Diseñe, despliegue y gestione una plataforma de ingeniería de datos de extremo a extremo.
