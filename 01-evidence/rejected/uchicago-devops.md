### **DevOps**


Comprende el ciclo de vida del software aprendiendo procesos de


desarrollo para acelerar el tiempo de comercialización de entregas


de software.


DevOps es la combinación de enfoques, prácticas y herramientas que


optimiza la capacidad de una organización para ofrecer servicios y


aplicaciones a gran velocidad y escala. Ayuda a crear y mejorar


productos más rápido y de forma más fiable que el desarrollo de


software tradicional. Toma medidas concretas para construir, probar y


mantener la coherencia con futuras versiones de software que sean


rápidas, fiables, escalables y que se adaptan a las necesidades


cambiantes de IT.

### **Sobre el Curso**

Nuestro curso online de ocho semanas se centra en los fundamentos


de DevOps y en aspectos clave como su implementación,


lanzamiento, control de versiones, pruebas, maquetado, y clouding.


Obtén la experiencia práctica que necesitas con Amazon Web


Service, Datadog, Docker, Git, Jenkins, Kubernetes, el entorno Linux,


Maven, Python, VMware y más. Al finalizar el curso, podrás diseñar e


implementar un entorno DevOps completo para conseguir


resultados eficientes y más rápidos para  tu organización.


Además, aprenderás a:


- Implementar la integración continua y reducir el tiempo de


comercialización de software.


- Diseñar una infraestructura completa para lanzar, configurar,


probar y monitorear el software.


- Crear una arquitectura de virtualización y nube relacionada


con DevOps.

### **¿A Quién está Dirigido?**

Este curso está diseñado para colaboradores individuales, ingenieros,


técnicos y profesionales interesados **​** en tecnología que quieran


comprender las prácticas de DevOps y el ciclo de vida del software.


Los participantes aprenderán sobre los procesos de desarrollo


optimizados que logran resultados más rápidos para la


comercialización de implementación de software. Aunque este curso


es de naturaleza técnica, es relativamente autónomo. Por lo tanto,


aquellos participantes que no tengan experiencia en programación


obtendrán suficiente información para construir una aplicación

DevOps con plena confianza.

### **Guía Académica**

El curso DevOps profundiza en los siguientes temas:


Módulo 1: Introducción a DevOps I


- Descripción general de DevOps.


- Sistemas operativos.


- Scripting y automatización de tareas.


- Clouding.


- Virtualización.


Módulo 2: Introducción a DevOps II


- Descripción general de DevOps (continuación).


- Sistemas operativos (continuación).


- Scripting y automatización de tareas (continuación).


- Clouding (continuación).


- Virtualización (continuación).


Módulo 3: Desarrollo del Flujo de Trabajo


- Implementación y/o creación de software.


- Vinculación de software a bibliotecas externas.


- Identificar cuándo y cómo actualizar las bibliotecas.


- Usar un compilador para traducir el lenguaje de programación a


lenguaje de máquina.

<!-- fin de página 7 -->

Módulo 4: Lanzamiento y Control de Versiones de Archivos


- Implementación de procesos de gestión de cambios.


- Programación de lanzamientos de nuevas versiones.


- Utilizar un administrador de código como GitHub.


- Automatización del lanzamiento de una nueva versión de software.


Módulo 5: Pruebas


- Pruebas funcionales.


- Pruebas de carga/rendimiento.


- Pruebas de regresión.


Módulo 6: Implementación y Empaquetado de Software


- Copiar y cargar software en una máquina determinada.


- Identificar los puntos fuertes y débiles de los diferentes métodos


de maquetado.


- Seleccionar el método de maquetado óptimo para


contextos particulares.


Módulo 7: Configuración


- Identificar prácticas efectivas de gestión de bases de datos y

seleccionar entre diferentes formatos para almacenar configuraciones


de software.


- Utilizar servicios de malla para conectarse y comunicarse entre


componentes independientes y diferenciados del sistema de software.


- Desarrollar métodos para realizar un seguimiento de los cambios en


las configuraciones de software.

<!-- fin de página 8 -->

Módulo 8: Monitorización


- Utilizar el software Data Dog para recopilar datos de usuario y


métricas gráficas en tiempo real.


- Establecer el umbral de cada métrica para identificar y reportar


problemas.


- Seleccionar métricas para registrar y tomar decisiones sobre cómo


almacenar, comprimir y archivar registros.
