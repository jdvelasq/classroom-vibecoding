# Fundamentos de data para analítica

## Propósito

Presentar a estudiantes de pregrado los aspectos de ingeniería de datos
que una persona de analítica necesita para obtener, integrar y preparar
los datos de una pregunta analítica, en un punto intermedio entre la
ingeniería de datos y la analítica.

## Resultados del curso

### RC01. Obtener e integrar datos

- Enunciado: Obtener e integrar los datos de dos o más fuentes que
  necesita una pregunta analítica dada, en un conjunto de datos único y
  documentado.
- Competencias: C002.
- Evaluación: Conjunto de datos integrado para una pregunta dada, con la
  descripción de cada fuente, de cada unión y de las decisiones tomadas
  para resolver inconsistencias entre fuentes [C002].

### RC02. Evaluar la calidad de los datos

- Enunciado: Evaluar la calidad de un conjunto de datos frente a una
  pregunta analítica, con reglas de validación que detecten faltantes,
  duplicados y valores fuera de rango.
- Competencias: C002.
- Evaluación: Reporte de calidad con las reglas aplicadas, los problemas
  encontrados y la corrección de cada uno [C002].

### RC03. Entregar datos listos para el análisis

- Enunciado: Construir un flujo reproducible que entregue un conjunto de
  datos analítico listo para explorarse con resúmenes y visualizaciones.
- Competencias: C002, C003.
- Evaluación: Flujo ejecutable de principio a fin y una exploración
  inicial que muestra que los datos responden la pregunta [C002; C003].

### RC04. Documentar el gobierno y la privacidad de los datos

- Enunciado: Documentar un plan de gestión de datos para una pregunta
  analítica dada, que identifique los datos personales o sensibles y las
  medidas para protegerlos.
- Competencias: C002.
- Evaluación: Plan de gestión de datos con las fuentes, los datos
  sensibles identificados y las medidas de protección propuestas para
  un caso dado [C002].

## Alcance

- El curso enseña a intervenir en el origen y la organización de los
  datos para analizar: de dónde vienen, qué significan, con qué calidad
  llegan, y cómo se integran y agregan para alimentar el análisis y la
  inteligencia de negocios (ingesta, ETL/ELT, modelado y agregación para
  BI, formatos y particionamiento).
- Para buena parte de sus estudiantes puede ser la única formación en
  inteligencia de negocios, por eso la trata de forma completa aunque se
  solape con cursos de posgrado de otra población.
- La administración, la operación y el rendimiento de bases de datos y de
  plataformas quedan fuera: es ingeniería de datos como disciplina
  autónoma.
- El procesamiento distribuido se introduce de forma conceptual,
  emulando sus operaciones en Python; las plataformas como Spark son
  profundidad del curso de posgrado de grandes datos.
- La operación productiva según DataOps y MLOps (orquestación, pruebas
  como reglas de producción, despliegue y monitoreo) es profundidad del
  curso de posgrado de productos de datos.
- La modelación predictiva y prescriptiva y la arquitectura empresarial
  de datos quedan fuera del curso.
