# RA03. Construir el conjunto de datos analítico

## Enunciado

Construir, a partir de datos imperfectos dispersos en varias fuentes de
una organización real o realista, un conjunto de datos analítico
documentado, con su calidad evaluada y sus decisiones de limpieza e
integración justificadas.

## Partes del enunciado

- Verbo: construir.
- Objeto: un conjunto de datos analítico documentado, con su calidad
  evaluada.
- Condición: datos imperfectos dispersos en varias fuentes de una
  organización real o realista, con restricciones de privacidad y
  gobierno de datos.
- Nivel: el estudiante decide y justifica, frente a alternativas, cómo
  integrar, limpiar y validar los datos, sin una receta única, y
  documenta el resultado para que otros lo auditen.

## Competencias

- C002: la obtención, integración, limpieza y validación de los datos,
  con su calidad documentada.

## Evaluación

- Conjunto de datos integrado a partir de al menos dos fuentes, con el
  informe de calidad, el análisis de impacto de los problemas
  encontrados y el plan de gestión de datos [C002].
- Tabla analítica con un registro por entidad, lista para el modelado o
  la exploración, con la justificación de las decisiones de preparación
  tomadas [C002].
