# RA04. Construir una descripción analítica de una situación

## Enunciado

Construir, a partir de un conjunto de datos de una organización real o
realista, un reporte o tablero que describa con métricas y
visualizaciones qué ocurre, para quién, dónde y cuándo, y que refine la
pregunta analítica inicial con lo observado.

## Partes del enunciado

- Verbo: construir.
- Objeto: un reporte o tablero descriptivo con métricas y
  visualizaciones.
- Condición: un conjunto de datos de una organización real o realista,
  con una pregunta analítica inicial que debe refinarse a partir de lo
  observado.
- Nivel: el estudiante elige las métricas, los segmentos y las
  visualizaciones pertinentes para la audiencia, justifica esas
  decisiones y ajusta la pregunta inicial con lo que los datos muestran.

## Competencias

- C003: la exploración, el resumen y la descripción de los datos.

## Evaluación

- Reporte o tablero con métricas de negocio, segmentos relevantes y
  visualizaciones para la pregunta dada, con las recomendaciones que de
  allí se derivan [C003].
- Bitácora que muestra cómo la pregunta analítica inicial se refinó a
  partir de los patrones y las anomalías observados [C003].
